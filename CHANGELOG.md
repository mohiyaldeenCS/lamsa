# Changelog

## 1.1.0 — Expanded catalog and repository delivery

- Expand the illustrative inventory to 35 fragrances across five scent families.
- Add SKU, audience, volume, local imagery, and featured-product metadata.
- Add safe schema upgrades, repeatable seed data, advanced filtering, and pagination.
- Extend product administration and remove automatic demo-account creation.
- Add catalog regression tests, continuous integration, and English documentation.

## 1.0.0 — Photographic storefront and local commerce

- Add campaign/product imagery, self-hosted Tajawal typography, and responsive Arabic pages.
- Add accessible quick views, dedicated favorites, and fragrance recommendations.
- Implement transactional local checkout, order history, and order administration.
- Harden CSRF, sessions, redirects, password migration, and monetary formatting.
- Cover concurrent stock purchases, replay protection, cancellation, ownership, and rendered flows.

## 0.2.0 — Functional Arabic store

- Implement quantity-aware cart actions, favorites, inventory administration, and filters.
- Add the first Arabic RTL design and password hashing.

## 0.1.0 — Imported foundation

- Preserve the original Flask entry point, database models, account forms, routes, templates, and minimal styling.
- Historical stages are reconstructed imports; see [History](docs/HISTORY.md).
